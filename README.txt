OLIVETTA — SITIO WEB DEMO

Archivos:
- index.html: estructura de la página
- styles.css: diseño responsive
- script.js: navegación, filtros, animaciones y reserva por WhatsApp
- favicon.svg: ícono temporal

Cómo abrir:
1. Abre index.html con Chrome/Edge/Firefox.
2. Requiere conexión a internet para cargar Google Fonts, fotografías de Unsplash y mapa de Google.

Antes de publicar:
- Sustituir el wordmark temporal por el logo oficial de Olivetta.
- Sustituir las fotografías de referencia por fotografías propias/licenciadas del restaurante.
- Verificar que el WhatsApp +58 424 844 5789 continúe siendo el oficial.
- Confirmar dirección, horarios, carta, platos y precios actuales.
- Si se desea, conectar el menú a base de datos/panel administrador y las reservas a un backend.
